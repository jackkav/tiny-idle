# Docs index

Notes left for the next person or agent who works on Smallest Thing. Read in this order:

1. [handover.md](handover.md): current state, how to run and test, open problems, next steps. Start here.
2. [decisions.md](decisions.md): every design and technical decision so far, with the reason and what we rejected.
3. [research.md](research.md): the incremental game research behind the design, with sources and caveats.
4. [../DESIGN.md](../DESIGN.md): the feature contract (hooks) and the ownership table. This is the API for adding a mechanic.
5. [../README.md](../README.md): player-facing summary, file table and pacing numbers.

When you change a decision, edit `decisions.md` in the same commit. Keep the reason, not only the result.
